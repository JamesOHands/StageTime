# Stage Time — ChatGPT v0

The Back Room is the presence prototype defined in the agreed root [SPEC.md](../SPEC.md). It runs as plain JavaScript ES modules on the same GitHub Pages site as Claude's separate bake-off build. No backend, scoring, AI, recording, persistence or build step.

**Headset / desktop URL:** https://jamesohands.github.io/StageTime/chatgpt-v0/

## First run

1. Open the URL in Quest Browser (or Chrome on the desktop).
2. Choose timed reactions for the first run. Enable the microphone on the setup page only if you want the optional pause detector and are happy to grant permission. A missing or denied microphone falls back to timed mode.
3. Set a comfortable volume and lighting. Leave the countdown visible for the first test. Use a clear standing space and both controllers.
4. Choose Enter VR. You are standing on the stage; the room is aligned once to your initial forward direction. Your tracked height is unchanged and there is no virtual locomotion.
5. Hold the right thumbstick for one second to start or stop the set. Hold both grips for one second to exit VR, or use the headset's system exit.

The desktop button enters the same scene at an eye height of 1.7 m. Click/drag the room to look around; Esc releases the mouse. Space starts/stops the set. On-screen controls are also available.

| Action | Quest | Desktop |
|---|---|---|
| Start/stop | Hold right thumbstick 1 s | Space |
| Laugh | A | L |
| Titter | B | T |
| Ripple (additional desktop test) | — | R |
| Applause | X | P |
| Cough | Y | C |
| Debug overlay | Left thumbstick press | D |
| Volume | Right thumbstick up/down | + / − |
| Exit | Hold both grips 1 s; system exit | Return to setup |

The stage surface is at y=0 in the local-floor reference space. Audience floor is −0.45 m. Thirty chairs are always present, with 20 occupied by default. A mic stand is on the stage. No handheld controller model is needed for v0.

## Repeatable tests

The entry page exposes a seed, seats, and duration; URLs can set the same parameters:

- `?seed=stage-test&fill=20&mode=timed&minutes=5`
- `?seed=stage-test&mode=manual&minutes=1` for a short control test.

Seeded appearance, idle motion, schedule and reaction streams are independent. The timed timeline uses session-clock deadlines, not random draws on every frame. Ambient coughs, glass sounds and shuffles are a separate schedule; when using manual mode, the room-tone bed is the only autonomous sound.

## Development and checks

Serve the repository root (not a file:// URL):

```sh
python3 -m http.server 8000
```

Open http://localhost:8000/chatgpt-v0/. Three.js and add-ons are pinned to the agreed 0.187.0 release via the import map. No npm install is needed to run the website.

Optional development-only tools in this build folder:

```sh
cd chatgpt-v0
npm ci
npm run check
npm test
npx playwright install chromium
npm run test:browser
```

The browser suite runs a loopback server with the GitHub Pages-style /StageTime/ prefix, checks desktop controls and a real one-minute countdown, simulates a denied microphone, and uses Chromium's fake microphone to check track cleanup. Use CHROMIUM_PATH for an installed Chromium. STAGETIME_TEST_LOCAL_THREE=1 can serve the identical pinned npm dependency during a network-isolated test; production remains on the agreed CDN. STAGETIME_BROWSER_QUICK=1 skips the actual minute for a smoke test.

The Node suite covers 30 physical seats, layout and schedule repeatability at normal/throttled frame intervals, reaction participants and weights, attention, the session clock, pause/echo gating and synthetic Quest controller mappings. The geometry test checks 30 animated members across several seeds. See the root TEST_LOG.md for completed tests; a synthetic controller test or desktop frame rate is not a real Quest test.

## Audio assets and privacy

All venue geometry, textures and initial sound placeholders are generated by this build. No third-party image, model, recording or font assets are included. Three.js is MIT licensed.

Both builds read the common [assets/audio/manifest.json](../assets/audio/manifest.json), documented in [assets/audio/README.md](../assets/audio/README.md). When licensed clips appear, this build will decode those listed files; an empty or absent bank falls back to original synthesised sounds. Ripple uses the shared laugh bank when no separate ripple is listed. The audio is built from individual seat sources with HRTF positioning, staggered playback, a 24-reaction-voice cap and master volume/limiting. The final bake-off still needs the same real sound library in both builds.

Mic permission is requested only by the setup button. The analyser provides local RMS levels to the pure speech detector; it is not connected to audio output. There is no MediaRecorder, speech-to-text, upload, analytics, storage or private rehearsal log. Desktop stop/finish and exit/page hide stop the actual mic tracks. Within VR, stopping pause detection retains an opted-in mic until exiting the immersive session to avoid an invisible permission prompt. Exiting releases every track.

## Headset acceptance (not yet performed)

Use the same headset and agreed settings for both builds. Run H1–H7 in the root spec; in particular:

- Confirm natural stage height, stable orientation and clear front-row faces.
- Toggle the debug overlay and note refresh rate and lowest FPS across five minutes. Check for judder or discomfort.
- Trigger laughs/coughs and turn your head; the sound should remain anchored to its seat.
- Verify manual controls and a timed fallback with the mic off/denied. Try mic mode separately if it is reliable.
- Finish a five-minute set. Decide privately whether you genuinely felt watched. The public test log is for technical results and the agreed single H7 answer only.

If the room, gaze, audio or comfort needs work, tune those before expanding the roadmap. The prototype uses placeholders and no headset is assumed to have passed yet.
